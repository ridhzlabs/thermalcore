Safety guarantees

  • Built-in thermal protection is never disabled or overridden.
  • Every write is validated and clamped to detected kernel capabilities.
  • Automatic snapshot + rollback if a profile apply fails.
  • Pre-install state backed up for full restore on uninstall.
  • No boot image / partition / SELinux modifications.
  • Lightweight: one small CLI, no background polling beyond the thermal guard.
